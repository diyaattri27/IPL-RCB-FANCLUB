# 🏏 Royal Challengers Bengaluru (RCB) Fan Website

A fan-made website dedicated to the **Royal Challengers Bengaluru (RCB)** for the **IPL 2025 season** 🎉.  
This project showcases the complete squad, match statistics, season schedules, news updates, and memorable highlights of the team.  

---

## 🚀 Features
- **Home Page**: RCB highlights, memorable moments, quick links, and hero section with visuals.  
- **Team Page**: Detailed player bios, achievements, best moments, and career stats.  
- **Stats Page**: Season-wise performance stats (2008–2025) with interactive charts.  
- **Schedule Page**: Match schedules & results from **2008–2025** with toss, margins, and outcomes.  
- **News Page**: Latest RCB updates and news snippets.  
- **Responsive Design**: Works on desktop and mobile devices.  

---

## 🛠️ Tech Stack
- **HTML5**  
- **CSS3**  
- **JavaScript (Vanilla JS)**  
- **Chart.js** (for stats visualization)
